# iPhone 12 Pro ケース（Symbea flower 刻印）設計メモ v0.1

Bambu Lab A1 mini・PLA で印刷する iPhone 12 Pro ケースを、ブラウザで調整して STL に書き出すツールの設計。
`order-chaos-stl` に `/case/` ページとして追加する。

## 1. 決定事項（2026-11-07）

| 項目 | 決定 |
|---|---|
| 素材 | PLA（Bambu PLA Matte） |
| 形 | 手持ちのクリアケースと同じ形式：背面板＋側壁。**下部（Lightning・スピーカー・マイク）、左右のボタン部は開放**。薄い壁で少したわんで着脱できる |
| 背面の厚み | **レンズ保護を優先**：2.7 mm（MagSafe 推奨の 2.1 mm 以下は満たさない） |
| モチーフ | **Symbea flower**（`Symbealab/Symbea-flower` の `symbea.js`）を背面に凹みで刻印 |
| 印刷の向き | 背面が下（ベッド面）。刻印はベッド面に掘り込む |

## 3. ケースの形状

### 3.1 断面（側壁）
- 内側 = 本体の形 + 隙間 `clr`（既定 0.20、フィット試験で決める）
- 壁の厚み `wall` 1.4（PLA でたわむ厚み。試験で 1.2–1.6）
- 前面のふち `lip`：画面側に 0.8 内側へ巻き込む（ガラスの平らな部分の始まり 1.15 より外側に収まる）。
  印刷時は上向きのオーバーハングになるので、下面は 45° 以上の傾斜にする
- 背面板 `back` 2.7 → レンズ面（1.72）より 0.98 外側（Apple のガラス保護基準 0.85 以上、推奨 1.0 にほぼ一致）

### 3.2 開口
| 開口 | 範囲（上端から） | 備考 |
|---|---|---|
| 電源側（正面から右） | 35.4–57.2 | サイドボタン ±(8.90 + 2) |
| 消音・音量側（正面から左） | 21.1–61.0 | 消音の上端 − 2 から 音量 − の下端 + 2 |
| 下部 | 正面から左端 13.3–58.3（中央 ±22.5） | 下の 2 隅だけ壁を残す。全開放にもできる |
| カメラ | 台座外形 + 0.5 | 角 R 7.5。外側の縁に 45° 面取り 1.0（フラッシュの光が反射しにくい・画角のキープアウト対策） |

開口の端はすべて丸める（R ≥ 1.5）。PLA の割れの起点を作らないため。

- カメラ穴とケース外周の間は約 1.6 mm しか残らない。この部分は壁と一体なので強度は保てるが、フィット試験で確認する
- 背面マイク（φ1.15）はカメラ穴の中に入るのでふさがない

### 3.3 刻印
- 位置：既定は中心 (35.76, 88)、外径 48。カメラ穴・外周から 4 mm 以上離す（UI で制約）
- 深さ 0.6（0.3–1.0）。背面板 2.7 なので刻印部でも 2.1 残る
- 最小の溝幅 0.6、最小の島 0.8：エレファントフット（1 層目のつぶれ）で埋まらないように、`pipeline.js` の太らせ・穴埋めを流用
- **背面から見て正しい向きになるように、STL の座標では左右反転して配置**（花はほぼ対称だが、シード文字などを入れる場合に効く）

## 4. 実装方針

```
Symbea flower（シード・花番号・変化）
  └─ symbea.js の写像＋層の変形を Worker に移植 → 密度場
       └─ pipeline.js：トーン → しきい値・太らせ → 輪郭（marching squares + Douglas–Peucker）
            └─ manifold-3d（WASM, Apache-2.0, vendor/ に同梱）
                 外殻（断面を重ねて hull）− 本体形状 − 開口 − 刻印（輪郭を押し出し）
                   └─ three.js プレビュー → STL（閉じた形状チェック）
```

- `vendor/` に manifold-3d を同梱（CDN に依存しない。GitHub Pages でそのまま動く）
- 本体形状：Detail A の角 × Detail B の縁の丸みで、断面を z 方向に重ねてロフト → hull
- 画面のパラメータ：シード／花番号、花の大きさ・位置・回転、刻印の深さ・線の太さ・しきい値、`clr` `wall` `back` `lip`、
  下部の開放幅、プリセット（試験片／本番）

## 5. 試作の段取り

| Step | 内容 | 判定 |
|---|---|---|
| 1 | フィット試験片：上端 25 mm（カメラ穴・角・ふちを含む）を `clr` 0.15 / 0.20 / 0.25 で 3 個 | 入れやすさ・ガタ・カメラ穴の位置 |
| 2 | 刻印試験片：40 mm 角・厚み 2.7 の板に、深さ 0.4 / 0.6 / 0.8 × しきい値 2 段 | 線のつぶれ・見え方（ベッド面の質感） |
| 3 | `/case/` UI の実装（Step 1・2 の結果を既定値に） | STL が閉じた形状・A1 mini に収まる |
| 4 | 全体を印刷 → 着脱・ボタン操作・カメラ写り（フラッシュ写り込み）を確認 | — |
| 5 | Order&Chaos または Symbea-flower の GitHub Pages に公開 | — |

### 印刷設定のめやす（PLA・A1 mini）
- 0.12 mm Fine、Arachne、壁ループ 3
- ベッド面が製品の外側になるので、テクスチャ PEI だとざらっとした質感、スムース PEI だと艶あり。刻印の見え方が変わる
- エレファントフット補正 0.1–0.15
- ふちのオーバーハングがだれる場合は、0.08 mm 層にするか、ふちの傾斜を大きくする

## 6. v0.2 実装メモ（2026-11-07）

### 決定事項の追加
| 項目 | 決定 |
|---|---|
| 置き場所 | `Symbealab/iphone-Case` に単独で作る（order-chaos-stl の `js/pipeline.js`・`vendor/`・`css/style.css` をコピー）。`case/` は order-chaos-stl にもそのまま入る配置 |
| フィット試験片 | 上端 **42 mm**（カメラ穴全体・消音側の開口の始まりを含む）。25 mm ではカメラ穴（〜39 mm）が途中で切れる |
| 刻印試験片 | 本番と同じ縮尺（外径 48）のまま、中央 **34 mm 角**を 40 mm 角の板に刻印 |
| 下部 | 既定は **壁あり（角も含む）**。「角だけ残す」「全開放」をパラメータで選べる |

### 実装で決まったこと・分かったこと
- **ふちの下面**：本体の縁の丸み（0.85 × 1.1 の楕円）に、隙間の分だけ外で接する 45° の面にした。
  45° の面のままでは前面ガラスの高さで 0.36 mm しか内側に入れないので、面をガラスより上まで延ばし、
  側面から 0.8 内側に入ったところ（ガラスから 0.44 mm 上）を先端にした。ふちの上面はガラスから 1.24 mm 上
- **花の線の取り出し**：Symbea の花は半透明の層を重ねた絵なので、トーンのしきい値だけでは面全体が刻印になる。
  トーンから半径 1.0 mm でぼかしたトーンを引く（ハイパス）と、層の縁・折り返しの濃い筋だけが残る。
  モモ（シード 342717359454 の花 7）のように線で描かれた花がきれいに出る。面を塗る花（ニゲラなど）は 48 mm では細かい点に分かれやすい
- **電源側の開口**：サイドボタン 46.31 ± 8.90 に 2 mm を足すと 35.41–57.21。指定の 35.4–57.2 では下側の余裕が 1.99 mm（0.1 mm 単位に丸めた分）
- **カメラ穴とケース外周の間**：ベッド面で約 1.6 mm（面取り 1.0・外周の面取り 0.5 を含む）。設計メモの見込みどおり
- 移植した花は、Symbea Flower のサイトと 3 シード × 9 マスで相関 0.997〜0.999（`tools/compare-symbea.js`）
